# YourImpact GitHub Pages Build

This folder contains the static website files that GitHub Pages can host directly.

Upload everything in this folder to your GitHub Pages branch or repository root:

- `index.html`
- `404.html`
- `favicon.png`
- `.nojekyll`
- `assets/`

The Replit server, PostgreSQL database, cache folders, and Replit plugins are not needed for this build. Login, donation history, XP, streaks, profile data, and achievements now save in the visitor's browser using `localStorage`.
